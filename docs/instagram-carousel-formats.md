```

Slide 4: Example / Proof
```

## Visual Rules

- Dark background (#0a0a0a or similar)
- Minimal text (max 15 words per slide)
- One idea per slide
- Bold typography for hooks
- Subtle for explanations
- Red accent color for CTAs
- No stock photos, no generic graphics
- Premium, clean, editorial feel
