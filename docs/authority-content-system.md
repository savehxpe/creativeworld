# Authority Content System

Outworld Creative + saveHXPE — Internal  
Branch: creative-director

---

## Purpose

Turn source-backed research into daily authority content — X posts, Instagram carousels, and short-form founder videos. Every piece of content is sourced, useful, and calm. No clickbait, no fake controversy, no unsourced hot takes.

---

## The Pipeline

```
Source Radar → Source → Insight → Script → Content → Post
```

---

## Script Format (All Authority Content)

```
1. Hook — Stop the scroll in 3 seconds
2. Source-backed insight — "According to [public source]..."
3. Personal point of view — "What this means for creators/brands..."
4. Business lesson — "The takeaway for [audience]..."
5. Outworld proof angle — "This is what we're building..."
6. Soft CTA — "Built by Outworld Creative. For brand work: team@outworldcreative.com"
```

---

## Content Types

| Type | Platform | Length | Use |
|------|----------|--------|-----|
| X post | X/Twitter | 280-500 chars | Daily insight |
| Carousel | Instagram | 7 slides | Deeper breakdown |
| Short video | Reels/TikTok | 30-60s | Founder authority |
| Hyperframes video | YouTube/IG | 60-120s | Deeper dives |

---

## Daily Content Flow

```
Morning:
1. Check source radar (10 min)
2. Pick 1 signal
3. Write 1 X post
4. Write 1 carousel idea
5. Save to memory

Weekly:
1. Review top performing posts
2. Expand best into Hyperframes video
3. Send stakeholder update
```

---

## Tone Rules

| Do | Don't |
|----|-------|
| Cite public sources | Make unsourced claims |
| Calm, credible delivery | Fake controversy or urgency |
| Personal POV grounded in experience | Pretend to be an economist |
| Business lesson that's actionable | Abstract theory |
| Soft CTA | Hard sell |
