Outworld Creative + saveHXPE — Internal  
Branch: creative-director

---

## Purpose

Produce source-backed founder authority videos using Hyperframes as the editing and motion layer. Kie and Suno are optional visual and sound supplements — not required for basic editing.

---

## Tool Roles

| Tool | Role | Required? |
|------|------|-----------|
| **Hyperframes** | Editing, subtitles, motion graphics, cards, rendered output | Yes — primary editor |
| **Kie (Nano Banana)** | Optional visual inserts, product stills, cinematic assets, logo animations | Optional |
| **Suno** | Optional background loops or brand sound | Optional |

---

## Workflow: Build → Integrate → Tune

### 1. Build (Storyboard First)
- Write the script (source-backed format)
- Mark timing: hook (0-3s), insight (3-20s), POV (20-40s), lesson (40-55s), CTA (55-60s)
- Note which sections need visuals (cards, clips, screen recordings)
- Decide if Kie/Suno inserts are needed

### 2. Integrate (Edit in Hyperframes)
- Import primary footage (speaker/desk shot)
- Add text cards at marked timestamps
- Add any Kie-generated stills as B-roll
- Add Suno background loop (low volume, no vocals)
- Add subtitles
- Add motion transitions between sections

### 3. Tune (Polish)
- Review timing — does the hook land in 3s?
- Check audio levels
- Verify source citations are visible
- Export at 1080p, 9:16 (vertical) or 16:9 (horizontal)
- Save project file + final export
