# Memory System

Outworld Creative — Internal Knowledge Engine  
Branch: creative-director

---

## Purpose

Store what worked, what failed, and what should be reused. The memory system makes Outworld Creative smarter every week.

---

## Memory Directories

| Directory | What Gets Stored |
|-----------|-----------------|
| `memory/brands/` | Client brand notes, preferences, style guides, contact history |
| `memory/campaigns/` | Campaign results — what ran, performance data, what to repeat |
| `memory/hooks/` | Winning hooks archive, failed hooks with notes on why they failed |
| `memory/sounds/` | Sound directions that resonated, client sound preferences |
| `memory/wins/` | Confirmed wins with before/after, metrics, client quotes (with permission) |
| `memory/losses/` | What didn't work, why, and the lesson extracted |

---

## How Memory Improves the System

1. **Before every new client project:** Search memory for similar niches, hooks, and campaigns
2. **After every campaign:** Save results, extract lesson, tag for searchability
3. **Weekly review:** Scan `memory/losses/` and `memory/wins/` — feed insights back into skills
4. **Monthly consolidation:** Remove duplicates, update best practices, retire outdated patterns

---

## Entry Format

```markdown
# [Brand/Project Name] — [Date]

## Context
Niche, market, goal, budget range

## What Happened
Description of what was created and deployed

## Result
Quantified outcome (bookings, sales, engagement, feedback)

## Lesson
One clear insight extracted

## Tags
niche, format, emotion, platform, outcome
```
