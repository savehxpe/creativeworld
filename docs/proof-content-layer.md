# Proof Content Layer

Outworld Creative — Internal  
Branch: creative-director

---

## Purpose

Turn Outworld's existing creative engines into tangible proof content — demo scripts, ad variations, localization samples, app sound demos, and founder case studies. No new backend systems. Just documentation and demo frameworks that show what Outworld can do.

---

## What It Produces

### 1. Ad-Fatigue Demos
One product. Ten creative angles. Proves Outworld can produce high-volume ad variations for brands and agencies that need to test creative fast.

### 2. Localization Demos
One generic ad adapted for 5 different markets. Proves Outworld can adapt creative through language, rhythm, music, and cultural context.

### 3. App Sound Demos
Four signature sounds for a fintech or mobile app. Proves Outworld understands sonic identity for digital products.

---

## The Rule

```
Show proof. Not promises.
```

Every demo is spec work — not client work unless the client approves public use. Every demo is labeled "Spec creative direction by Outworld Creative."

---

## Integration with Existing Systems

| Engine | Powers |
|--------|--------|
| `spec-ad-engine` | Generates ad variations for fatigue demo |
| `brand-sound-engine` | Generates sound directions for all demos |
| `visual-direction-engine` | Generates visual directions for fatigue + localization |
| `localization-adapter` | Generates market adaptations |
| `kie-image-prompt` | Generates still images for demos |
| `suno-brand-sound` | Generates sound assets for app sound demo |

- [ ] Every demo is labeled "Spec creative direction by Outworld Creative"
