# Stakeholder Proof System

Outworld Creative + saveHXPE — Internal  
Branch: creative-director

---

## Purpose

Build trust with key stakeholders — Dre Moon, Andy, Radical Publishing, and others — through consistent commercial proof. Show progress without begging. Let the work speak.

---

## Who Gets Updates

| Stakeholder | Relationship | Update Frequency |
|-------------|-------------|-----------------|
| Dre Moon | Producer, collaborator | Weekly |
| Andy / Radical Publishing | Publishing, business | Weekly |
| Future stakeholders | As relationships develop | Weekly |

---

## Weekly Update Format

Every update follows the same 7-section format:

```
1. What I built this week
2. What proof assets are live
3. What I posted
4. What leads I contacted
5. What I learned
6. What I'm doing next
7. Where support would help
```

---

## Tone Rules

| Do | Don't |
|----|-------|
| Calm, factual, proof-led | Desperate or begging |
| Show what shipped | Ask for money without showing value |
| Be honest about challenges | Pretend everything is perfect |
| State specific next steps | Vague "working on things" |
| Ask for specific support | General "help me out" |

---

## What Counts as Proof

- Landing page is live
- Spec Ad Lab has 9 campaign concepts
- Playwright test suite passes (57/57)
- Kie API pipeline works
- Suno brand sound pipeline works
- Signal Desk content engine is built
- New client contact made
- New spec ad concept created
- New brand sound pack ready
- New demo asset generated

---

## Delivery

Updates can be:
- A single Notion page (shared link)
- A WhatsApp/Telegram message
- A brief call with the update as agenda
- A recorded 2-minute video walkthrough

The format matters less than the consistency. Updates must happen weekly.
