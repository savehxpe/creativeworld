# Outworld Creative Intelligence System

Outworld Creative  
Private operating system  
Branch: creative-director

---

## What This Is

Outworld Creative uses a private creative intelligence system to diagnose brand problems, create ads, build campaign ideas, write scripts, create brand sound, and turn attention into business outcomes.

This is not fake science. It is practical business logic applied to creative direction.

---

## How It Works

The system has 15 internal skills. Each skill is a decision framework, not a magic tool. They help Outworld think faster, deeper, and more consistently than a typical agency.

**The rule:** Show 20% on the website. Hide 80% in the backend.

The public sees clean creative direction. The backend runs the logic that makes the creative sharp.

---

## The 15 Skills

| # | Skill | What It Does |
|---|-------|--------------|
| 1 | **Attention Engine** | Scores hooks and first-3-second stopping power |
| 2 | **Virality Engine** | Estimates whether content can spread using network math |
| 3 | **Network Engine** | Maps who to reach and who connects to who |
| 4 | **Revenue Leak Engine** | Finds where brands lose money and quantifies it |
| 5 | **Brand Sound Engine** | Creates jingles, 5-second tags, and campaign sounds |
| 6 | **Visual Direction Engine** | Defines lighting, mood, colour, framing, and motion rules |
| 7 | **Spec Ad Engine** | Turns weak brands into premium ad concepts |
| 8 | **UGC Script Engine** | Writes ads that feel like content, not ads |
| 9 | **Comparison Desk Engine** | Creates fact-driven comparison content |
| 10 | **Signal Desk Engine** | Tracks news, trends, platforms, and creator economy |
| 11 | **Outreach Engine** | Writes DMs, emails, and follow-ups that get replies |
| 12 | **Proposal Engine** | Turns diagnosis into custom proposals |
| 13 | **Case Study Engine** | Tracks before/after, results, and learnings |
| 14 | **Memory Engine** | Saves what worked so the system improves weekly |
| 15 | **Motion Site Engine** | Defines motion rules for the website |

## The Workflow

```
Client / trend / brand
    ↓
Diagnosis (Revenue Leak Engine + Attention Engine)
    ↓
Spec ad concept (Spec Ad Engine + Visual Direction Engine + Brand Sound Engine)
    ↓
Image prompt (Visual Direction Engine)
    ↓
Nano Banana still (Kie.ai)
    ↓
Seedance / Kling video (Kie.ai)
    ↓
Brand sound (Brand Sound Engine)
    ↓
Post / ad / proposal (Outreach Engine + Proposal Engine)
    ↓
Save learning (Memory Engine + Case Study Engine)
```

## Language Rules

**Public (website, client-facing):**
- Simple, direct, premium
- No quantum, no math jargon, no "AI-powered everything"
- "Video ads and brand sound" — not "sonic advertising ecosystem"

**Private (internal skills, team use):**
- Can use frameworks, models, and decision logic
- Can reference K-factor, SIR models, Bayesian thinking
- Can be technical because it's internal

**Never public:**
- "We use 15 PhDs"
- "Quantum creative algorithms"
- "AI replaces creative directors"
- Internal engine names as selling points

## The Goal

The goal is not to sound smart. The goal is to be useful in every room:

- Restaurant? Diagnose bookings and content.
- Fashion brand? Build drop ads and brand sound.
- Hotel? Build desire and weekend campaigns.
- Event? Build FOMO.
- Fintech? Simplify trust and explain products.
- Artist? Build rollout systems.

The system makes Outworld useful. The website makes Outworld trusted.
