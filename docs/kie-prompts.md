## Kie.ai API Usage (If Using API Instead of Web Interface)

### API Endpoint
```
POST https://api.kie.ai/v1/generate
```

### Nano Banana API Call
```json
{
  "model": "google/nano-banana-2",
  "prompt": "[PROMPT TEXT FROM ABOVE]",
  "width": 1024,
  "height": 1280,
  "aspect_ratio": "4:5",
  "negative_prompt": "text, watermark, logo, signature, brand name, distorted hands, extra fingers, plastic skin, blurry, low quality, generic stock photo, Canva template look",
  "num_images": 1
}
```

### Seedance 1.5 Pro API Call
```json
{
  "model": "seedance-1-5-pro",
  "type": "image-to-video",
  "image_url": "[URL OF NANO BANANA OUTPUT IMAGE]",
  "prompt": "[MOTION PROMPT FROM ABOVE]",
  "duration": 5,
  "fps": 24,
  "aspect_ratio": "9:16"
}
```

**Note:** If using Kie.ai web interface, simply paste the prompts above into the respective model playgrounds.

## Quality Checklist Before Generation

- [ ] Prompt includes "No text, no logos, no fake brand names"
- [ ] Prompt specifies vertical 4:5 aspect ratio
- [ ] Prompt describes strong subject focus and intentional lighting
- [ ] Negative prompts exclude distorted hands and plastic skin
- [ ] Prompt matches campaign emotion and goal
- [ ] Seedance prompt describes first-second hook mechanic
- [ ] Seedance prompt specifies 5-second duration
- [ ] Audio direction included for Seedance

---

## Post-Production Steps

1. **Download all generated assets** from Kie.ai within 14 days (retention policy)
2. **Store locally** in `/assets/spec-lab/` directory
3. **Add text overlays in Canva/Figma/HTML** (not in AI image)
4. **Create mock social post frames** for portfolio display
5. **Label each asset** with campaign name and "Spec creative direction by Outworld Creative"
6. **Compress for web** if needed (landing page optimization)
