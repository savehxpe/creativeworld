# OpenClaw Operating Rules

Outworld Creative — Internal  
Branch: creative-director

---

## Purpose

OpenClaw is the recurring operator for Outworld Creative. It organizes, schedules, and executes approved workflows while respecting strict security boundaries.

---

## OpenClaw MAY

- Run approved scripts in `scripts/` directory
- Organize docs in `docs/` directory
- Schedule routines (daily content, weekly reviews)
- Update memory files in `memory/`
- Save research sources to `memory/`
- Generate Signal Desk content drafts
- Find leads using approved research tools
- Generate outreach angles from brand data
- Update asset manifests and track outputs

---

## OpenClaw MAY NOT

- Read `.env` file
- Print or log API keys
- Delete files without explicit user confirmation
- Run paid API generation calls without explicit user confirmation
- Rewrite git history without explicit user confirmation
- Install external skills without explicit user confirmation
- Commit changes without user review
- Push to remote repositories without explicit user confirmation
- Modify the public website without approval

---

## Daily OpenClaw Routine

```
1. Run Signal Desk research topic
   → Use daily research sources from docs/news-research-sources.md
   → Save sources to memory

2. Generate 1 X post
   → Follow format: hook → insight → example → lesson → soft CTA
   → Save to memory

3. Generate 1 IG carousel idea
   → Follow 7-slide format
   → Save to memory

4. Find 5 leads
   → Use Firecrawl research or manual discovery
   → Save to memory/brands/

5. Generate 5 outreach angles
   → One per lead
   → Save to memory/campaigns/

6. Save daily results
   → memory/wins/ or memory/losses/ as appropriate
```

---

## Weekly Review

```
- Scan memory/wins/ for patterns
- Scan memory/losses/ for lessons
- Update skill engines with learnings
- Archive outdated entries
```
