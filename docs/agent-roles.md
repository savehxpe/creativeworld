# Agent Roles

Outworld Creative — Internal Operating Modes  
Branch: creative-director

---

## Purpose

Agent roles are internal operating modes for the Outworld Creative system. Each role has a specific purpose, a checklist, and clear rules about what good output looks like and what to avoid.

**These are never mentioned publicly.** They are not website sections. They are not client-facing titles. They are private operating instructions.

---

## The Roles

| Role | Purpose |
|------|---------|
| **Creative Director** | Generate premium creative direction — spec ads, campaigns, hooks, scripts |
| **Growth Strategist** | Analyze revenue gaps, competitors, market opportunities |
| **Brand Sound Director** | Create sonic identity, jingles, campaign sound design |
| **UI Polish Reviewer** | Review website copy, motion, layout, performance |
| **Security Reviewer** | Audit repo for exposed keys, env hygiene, git history leaks |

---

## How to Use Roles

Before generating any output, select the appropriate role. Read the role's purpose, checklist, and "what to avoid." Generate with those constraints active.

After generating, run the role's checklist against the output. If any item fails, revise.

---

## Role vs. Skill

- **Skills** (`/skills/`) are decision frameworks — how to think about a problem
- **Agent roles** (`agent-roles/`) are operating modes — how to generate specific outputs
- **Evals** (`evals/promptfoo/`) are quality gates — does the output pass?

Skills → Agent Roles → Evals → Client
