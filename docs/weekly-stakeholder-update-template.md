## Purpose

Standard format for weekly updates to stakeholders — Dre Moon, Andy, Radical Publishing, and future partners. Consistent. Calm. Proof-led.

---

## Template

Copy this template. Replace `[brackets]` with actual content. Save as `stakeholder-updates/YYYY-MM-DD-weekly-update.md`.

```markdown
# Weekly Update — [YYYY-MM-DD]

## 1. What I Built This Week
- [shipped thing]
- [shipped thing]

## 2. What Proof Assets Are Live
- Landing page: [URL]
- Spec Ad Lab: 9 campaign concepts visible
- Tests: 57/57 Playwright tests passing
- [other live assets]

## 3. What I Posted
- X: [post topic or link]
- Instagram: [carousel topic]
- [other platforms]

## 4. What Leads I Contacted
- [niche] brands contacted: [count]
- Replies received: [count]
- Discovery calls booked: [count]

## 5. What I Learned
- [key insight from the week]

## 6. What I'm Doing Next
- [next week priority 1]
- [next week priority 2]
- [next week priority 3]

## 7. Where Support Would Help
- [specific ask — connection, feedback, signal boost]
```

---

## Rules

- Every section must have at least one item
- Be honest — if nothing shipped, say so
- Quantify where possible (counts, URLs, metrics)
- Never beg. State what you need clearly and calmly
- Deliver on time. Weekly means weekly
