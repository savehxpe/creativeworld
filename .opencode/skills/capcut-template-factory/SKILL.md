# CapCut Template Factory

## Purpose
Create reusable short-form ad template blueprints for TikTok, Reels, Shorts, and CapCut-style editing. Platform-agnostic creative blueprints — not actual CapCut proprietary files.

## When to Use
- Building reusable ad templates for a client
- Creating spec template packs for portfolio proof
- Expanding Outworld's template library
- Generating consistent ad formats across campaigns

## Default Settings
```
aspect_ratio: 9:16
duration: 5–15 seconds
safe_zones: keep text away from platform UI
style: premium, simple, fast, mobile-first
audio: include brand sound slot or 15-second loop
```

## Template Blueprint Structure
Each template includes:
1. Template name
2. Niche
3. Use case
4. Duration
5. Aspect ratio
6. Clip count
7. Timeline structure (beat markers)
8. Text placeholders (per beat)
9. Visual placeholders (per beat)
10. CTA
11. Sound direction
12. Export notes
13. Client usage instructions

## 5 Starter Templates

1. **Product Drop** — Fashion, beauty, ecommerce. Product reveal, launch hype, scarcity.
2. **Restaurant Craving** — Restaurants, lounges, cafes. Food reveal, booking push, weekend promo.
3. **Hotel Staycation** — Hospitality. Room reveal, view reveal, weekend escape.
4. **UGC Testimonial** — Apps, beauty, services. Problem → reaction → result → CTA.
5. **Brand Sound** — Any brand. 3-second tag, 15-second loop, product reveal sound.

## Quality Check
- [ ] Timeline structure is clear and executable
- [ ] Beat markers align with visual and text placeholders
- [ ] CTA is specific to the ad goal
- [ ] Sound direction is included
- [ ] Safe zones respected (text away from platform UI)
- [ ] Template is reusable across similar brands in the niche
