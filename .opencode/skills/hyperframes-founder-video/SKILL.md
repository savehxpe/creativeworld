# Hyperframes Founder Video

## Purpose
Produce source-backed founder authority videos using Hyperframes as the editing and motion layer. Kie and Suno are optional supplements — not required for basic editing.

## When to Use
- Creating 30-60 second Reels/TikTok authority videos
- Producing 60-120 second YouTube/IG deep-dive videos
- Building spec demo walkthroughs with voiceover
- Making stakeholder update video summaries

## Workflow: Build → Integrate → Tune

### 1. Build (Storyboard First)
- Write the script (source-backed format)
- Mark timing: hook (0-3s), insight (3-20s), POV (20-40s), lesson (40-55s), CTA (55-60s)
- Note which sections need visuals
- Decide if Kie/Suno inserts are needed

### 2. Integrate (Edit in Hyperframes)
- Import primary footage (speaker shot)
- Add text cards at marked timestamps
- Add optional Kie-generated stills as B-roll
- Add optional Suno background loop (low volume)
- Add subtitles and motion transitions

### 3. Tune (Polish)
- Review timing — hook lands in 3s?
- Check audio levels
- Verify source citations are visible
- Export at 1080p, 9:16 (vertical) or 16:9 (horizontal)
- Save project file + final export

## After Each Strong Session
Update this skill with: what worked, what didn't, what Kie/Suno inserts added value, template tweaks discovered.

## Quality Check
- [ ] Script written and timed BEFORE editing
- [ ] Hook lands in under 3 seconds
- [ ] Source citations are visible or spoken
- [ ] CTA is clear
- [ ] No AI jargon in visible text
- [ ] Audio levels are balanced
