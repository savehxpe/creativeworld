# Micro-Licensing Pack

## Purpose
Build and sell pre-made downloadable packs of sounds, loops, textures, and visual assets. Passive revenue — build once, sell many times. Every asset must have confirmed commercial rights.

## When to Use
- Building a new asset pack for sale
- Expanding the Outworld micro-licensing catalog
- Packaging existing spec ad assets for resale
- Creating niche-specific sound or visual collections

## Pack Types

### Sound Pack
- 10 loopable background tracks
- 5 brand stingers
- 10 product reveal sounds
- 5 transition sounds

### Visual Pack
- 10 background textures
- 5 overlay templates
- 10 motion backgrounds

### Combo Pack
- Sound + visual bundles for specific niches
- "Creator Starter Kit" (sounds + overlays + textures)

## Process
1. Define the niche and use case
2. Generate assets (Suno for sounds, Kie for visuals)
3. Run `audio-rights-check` on EVERY sound
4. Select best 10-20 assets per pack
5. Export in standard formats (WAV + MP3 for sounds, PNG for visuals)
6. Write simple usage license
7. Package as downloadable zip
8. Set price and distribution channel

## Critical Rules
- [ ] ONLY include assets with confirmed commercial rights
- [ ] Every sound passes `audio-rights-check`
- [ ] Generation records kept: prompt, date, model, account tier, task ID
- [ ] Free-tier Suno outputs are NEVER included
- [ ] Usage license is clear: what buyer can and cannot do
- [ ] License grants usage rights, not "ownership" or "exclusive rights"
- [ ] AI-generated works not claimed as "copyrighted"
