# Plain Language Conversion Copy

## Purpose
Simplify Outworld Creative website copy so it is clear, premium, direct, and easy to understand in under 5 seconds. Cut unnecessary words. Remove jargon. Preserve confidence. Keep SEO simple.

## When to Use
- Before deploying any copy to the landing page
- When reviewing Signal Desk content
- When writing outreach templates
- When building new website sections

## Rules

### Words to Replace or Remove
| Avoid | Use Instead |
|-------|-------------|
| creative intelligence | helpful notes, ideas, direction |
| ecosystem | system, setup, way of working |
| infrastructure | setup, tools |
| scalable | can grow with you |
| automated | built, made, created |
| engine | tool, skill |
| sonic ads | brand sound |
| AI-powered (overused) | smart, fast, built |
| global creative systems | creative direction |
| conversion architecture | clear path to buy or book |
| proprietary | our own |
| revolutionary | new, better, different |
| algorithmic | smart, automatic |

### Words to Prefer
- video ads
- brand sound
- jingles
- hooks
- campaigns
- launch visuals
- content ideas
- Reels
- TikTok
- Shorts
- remembered
- seen
- heard
- sharper
- clear

### Tone Rules
- Max 20 words per sentence where possible
- No section should feel like a pitch deck
- No jargon a 15-year-old wouldn't understand
- Keep premium feel — not cheap, not corporate
- Confidence without hype

## Quality Check
- [ ] A 15-year-old understands every section
- [ ] A business owner knows what's being sold in 5 seconds
- [ ] No sentence longer than 20 words (where possible)
- [ ] No "creative intelligence," "ecosystem," "infrastructure," "scalable"
- [ ] No "automated," "engine," "sonic ads" (unless "Brand Sound" section heading)
- [ ] SEO keywords preserved: video ads, brand sound, jingles, short-form ads, Reels, TikTok, campaign ideas
- [ ] Tone is premium, not cheap, not buzzword-heavy
