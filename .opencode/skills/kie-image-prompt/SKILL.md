# Kie Image Prompt

## Purpose
Generate clean Nano Banana 2 prompts for Outworld Creative spec ad stills. Every prompt follows the brand's visual direction rules: premium, cinematic, high-arousal, South African / African-global.

## When to Use
- Before generating any spec ad still with Nano Banana 2
- When iterating on a visual that doesn't match the campaign direction
- When adapting a spec ad concept to a different niche

## Prompt Structure

```
Premium social media advertising image for [niche].
Campaign: [campaign name]
Goal: [business goal]
Emotion: [emotional trigger]

High-arousal commercial advertising.
Cinematic but realistic.
Premium South African / African-global visual language.
Designed to stop scrolling in under 1 second.
Strong subject focus: [subject description].
Clear negative space for headline.
Bold contrast: [contrast description].
Luxury but accessible.
Hero subject in foreground: [foreground detail].
Intentional premium lighting: [lighting description].
Looks like a campaign still from a serious modern creative agency.
Vertical 4:5.

No text.
No logos.
No fake brand names.
No messy typography.
No distorted hands.
No plastic AI skin.
No generic Canva look.
```

## Rules
- Always specify `4:5` aspect ratio
- Always include "No text. No logos. No fake brand names."
- Always include "No distorted hands. No plastic AI skin."
- Emotion must match the spec ad concept's emotional trigger
- Lighting must be specific, not "good lighting"
- Subject focus must be singular and clear

## Quality Check
- [ ] Prompt includes campaign name and goal
- [ ] Emotion is specified (FOMO, desire, escape, urgency, etc.)
- [ ] Niche is clearly stated (restaurant, fashion, hospitality, etc.)
- [ ] Negative constraints are present (no text, no logos, no plastic AI skin)
- [ ] Aspect ratio is 4:5
- [ ] Lighting is intentionally described
