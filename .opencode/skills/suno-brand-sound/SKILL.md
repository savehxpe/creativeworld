# Suno Brand Sound

## Purpose
Create simple brand sound concepts for ads, product drops, podcasts, Reels, TikTok, app cues, and campaign assets. Every sound should make a brand easier to remember.

## When to Use
- Generating 3-second brand tags
- Creating 15-second ad loops for social media
- Designing 10-second podcast or app intros
- Building campaign sound beds
- Creating product reveal sounds
- Building a complete Brand Sound Pack

## The Brand Sound Pack (Standard Deliverable)

```
Brand Sound Pack

For brands using random trending sounds but no memorable audio identity.

Includes:
- 3-second brand tag
- 15-second ad loop
- Product reveal sound
- Usage notes
- Optional pairing with a 5-second video ad (via Kie)
```

## Prompt Structure

```
Create a short loopable brand sound for a [NICHE] campaign.

Mood: [MOOD]
Use case: [3-second tag / 15-second social ad loop / 10-second intro]
Tempo: [BPM]
Style: modern, clean, memorable, minimal, premium
Avoid: vocals, copyrighted melodies, artist imitation, busy drums, long build-ups

The sound should feel like a brand cue people can remember after hearing it once.
```

## Niche Parameters

| Niche | Mood | Tempo (BPM) | Key Direction |
|-------|------|-------------|---------------|
| Restaurant | Warm, hungry, premium | 90-110 | Major, warm |
| Fashion | Dark, confident, street-luxury | 120-140 | Minor/major |
| Hospitality | Calm, expensive, escape | 70-90 | Major, airy |
| Beauty | Clean, smooth, feminine | 80-100 | Major, soft |
| Events | FOMO, nightlife, high-energy | 128-150 | Minor, heavy bass |
| Fintech | Modern, clean, trustworthy | 100-120 | Neutral, clean |
| Podcast | Sharp, intelligent, minimal | 90-110 | Minimal, sharp |

## Rules
- Always request `soundLoop: true` for Reels/TikTok use
- Always specify `instrumental: true` for brand use (no vocals)
- Never use artist names in prompts
- Never imitate known jingles or brand sounds
- Never imply AI music is "exclusive sync-ready" without verified rights
- Always run audio-rights-check before commercial delivery

## Quality Check
- [ ] Sound is recognizable in 1-2 seconds
- [ ] Matches the brand's niche and emotion
- [ ] Loops cleanly (no jarring transitions)
- [ ] Free from obvious reference imitation
- [ ] No artist names in prompt
- [ ] Commercial rights confirmed before delivery
