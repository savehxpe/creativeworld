# Ad Creative Pack

## Purpose
Generate high-volume short-form ad creative variations for brands, apps, ecommerce, and agencies. Each pack produces 10-50 distinct ad concepts with hooks, scripts, visuals, sound, and CTAs.

## When to Use
- Building an Ad Creative Pack for a paying client
- Responding to an agency request for white-label creative testing
- Creating spec ad packs for portfolio proof
- A client needs to test multiple creative angles simultaneously

## Output Per Variation
1. 5-second hook concept
2. 15-second ad script
3. Visual direction (lighting, composition, motion)
4. Sound direction (tag, loop, or reveal sound)
5. Caption
6. CTA
7. Platform-specific adaptation note (Reels / TikTok / Stories)

## Volume Options
- Test Pack: 10 variations
- Standard Pack: 25 variations
- Full Campaign Pack: 50 variations

## Process
1. Define the brand, product, and goal
2. Identify 3-5 creative angles to test (different emotions, hooks, formats)
3. Generate 5-10 variations per angle
4. Ensure distinctiveness (not 50 rewrites of the same concept)
5. Add sound direction to each variation
6. Flag top 3 per angle for visual mockup priority
7. Deliver in structured format (Google Doc / Notion)

## Quality Check
- [ ] Every hook creates an emotional reaction in 3 seconds
- [ ] Variations across angles are truly distinct
- [ ] Sound direction included for each variation
- [ ] CTA is specific to the ad goal
- [ ] No generic "we're the best" language
- [ ] Volume matches the pack tier (10/25/50)
- [ ] No pricing in client-facing output unless in a custom proposal
