# Source Radar

## Purpose
Find and track public sources for Outworld Creative and saveHXPE authority content. Use RSS feeds, GitHub repos, Firecrawl results, Google Alerts exports, and saved source lists. Never scrape private or restricted content. Never create claims without sources.

## When to Use
- Daily morning research routine
- Building weekly content calendars
- Preparing stakeholder updates with market context
- Finding signals for authority videos
- Expanding the source database

## Source Categories
AI tools, advertising, creator economy, music business, fintech, fashion, hospitality, ecommerce, African markets, GitHub/open-source tools, platform updates

## Output Format
```
# Source Entry — [Date]
Source: [URL]
Category: [category]
Signal: [1-2 sentence summary]
Relevance to Outworld: [why it matters]
Content angle: [how to turn into a post or script]
```

## Process
1. Scan sources (RSS, GitHub, Firecrawl, alerts) — 10 min daily
2. Extract 1-3 signals relevant to Outworld's markets
3. Rank by: timeliness, relevance, authority potential
4. Save to `sources/[category]/` or `memory/`
5. Feed top signal into authority content pipeline

## Quality Check
- [ ] Source is public and verifiable
- [ ] Signal is relevant to Outworld's niches
- [ ] No private or restricted content scraped
- [ ] No claims without linked sources
- [ ] Content angle is clear and actionable
