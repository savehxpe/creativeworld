# Streamer Kit

## Purpose
Generate pre-built visual and sound packages for streamers. Overlays, alert sounds, transition animations, stream intro loops, and brand sound kits.

## When to Use
- Building a standard streamer kit for sale
- Creating a custom kit for a paying streamer client
- Testing the streamer market with a few pre-made packs
- Adding streamer assets to the Spec Ad Lab as proof

## Kit Components

### Visuals
- 3 overlay templates (starting soon, BRB, stream ending)
- 2 transition animations
- 1 stream intro/outro animation
- Alert box template
- Chat box template

### Sounds
- 3 alert sounds (follow, sub, donation)
- 2 transition sounds
- 1 stream intro loop (15 seconds)
- 1 brand sound tag (3 seconds)

## Process
1. Define the streamer niche (gaming, music, podcast, IRL)
2. Design overlay templates at 1080p
3. Generate sound assets (Suno sounds endpoint)
4. Run `audio-rights-check` on EVERY sound
5. Export PNG (overlays) + WAV/MP3 (sounds)
6. Write simple setup guide (OBS/Streamlabs)
7. Package as downloadable zip
8. Set price

## Rules
- [ ] Overlays work at 1080p standard resolution
- [ ] Sounds are short and loop-ready
- [ ] Setup guide is simple enough for a non-technical streamer
- [ ] Every sound passes `audio-rights-check`
- [ ] Usage license is included
- [ ] This is a side offer — not the main revenue driver
