# Enterprise Demo Planner

## Purpose
Plan enterprise demos that prove Outworld's creative engine capabilities. Scope, inputs, outputs, assets needed, and what to show. No fake claims — only working demos count.

## When to Use
- Planning an ad-fatigue demo for an agency prospect
- Scoping a localization demo for a fintech or gaming client
- Building an app sound demo for a mobile product
- Preparing demo assets before a client pitch
- Expanding the demo portfolio

## Output Per Demo
- Demo name and public line
- Input required
- Output generated
- Assets needed (Kie stills, Suno sounds, templates)
- Demo format (page, video, interactive)
- Quality gate (demo works before it's shown)

## The 3 Current Demos
1. **Ad-Fatigue Fighter** — 10 variations from one product
2. **Localization Pipeline** — 5 market adaptations from one ad
3. **App Sound Identity** — 4 signature sounds for an app

## Rules
- [ ] Every demo labeled "Spec creative direction by Outworld Creative"
- [ ] No fake client logos or invented metrics
- [ ] No enterprise capability claims without working demos
- [ ] Demos are functional before being shown to any prospect
