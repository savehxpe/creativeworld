# OpenClaw Daily Operator

## Purpose
Execute recurring daily operator workflows for Outworld Creative. Signal Desk content, lead research, outreach preparation, memory updates.

## When to Use
- Daily morning routine
- Weekly review
- Content generation sessions
- Lead discovery sessions

## What OpenClaw MAY Do
- Run approved scripts in `scripts/` directory
- Organize docs in `docs/` directory
- Schedule routines (daily content, weekly reviews)
- Update memory files in `memory/`
- Save research sources to `memory/`
- Generate Signal Desk content drafts

## What OpenClaw MAY NOT Do
- Read `.env` file
- Print or log API keys
- Delete files without explicit user confirmation
- Run paid API generation calls without explicit user confirmation
- Rewrite git history without explicit user confirmation
- Install external skills without explicit user confirmation

## Daily Routine
1. Run Signal Desk research topic
2. Save sources to memory
3. Generate 1 X post
4. Generate 1 IG carousel idea
5. Find 5 leads
6. Generate 5 outreach angles
7. Save results to memory/wins or memory/campaigns

## Quality Check
- [ ] All tasks completed in sequence
- [ ] No API keys exposed
- [ ] Results saved to correct memory directories
- [ ] No unauthorized operations performed
