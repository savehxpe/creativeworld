# Proof Content Writer

## Purpose
Generate proof content from Outworld's creative engines — spec ads, ad variations, hooks, founder scripts, and demo assets. Turn internal capabilities into tangible proof.

## When to Use
- Building an ad-fatigue demo (10 variations from one product)
- Writing founder video scripts (under 60 seconds, calm tone)
- Creating localization demo variations (one ad → 5 markets)
- Generating spec content for the Spec Ad Lab
- Producing proof content for client pitches

## Process
1. Identify the demo type (ad-fatigue, localization, app-sound, founder-script)
2. Define inputs (product, brand, market, tone)
3. Generate variations using Outworld engines:
   - `spec-ad-engine` for ad variations
   - `brand-sound-engine` for sound directions
   - `visual-direction-engine` for visual directions
   - `localization-adapter` for market adaptations
4. Format output as spec creative direction
5. Label every piece: "Spec creative direction by Outworld Creative"

## Quality Check
- [ ] Every output labeled "Spec creative direction by Outworld Creative"
- [ ] No fake client claims or fabricated metrics
- [ ] Variations are truly distinct (not same concept reworded)
- [ ] Sound direction included with every variation
- [ ] Founder scripts are under 60 seconds
- [ ] Tone is calm, useful, founder-led — not hyped
- [ ] No AI tool names mentioned in public output
